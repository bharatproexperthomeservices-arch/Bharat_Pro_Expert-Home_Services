# Customer Android App

Reserved client application in the unified Bharat Pro Expert workspace.

Target: Android / Google Play Store.
Backend: shared Supabase project.
Authentication: Google OAuth and phone OTP (sign-up/sign-in).
Customer data, service catalogue, prices, packages, add-ons, bookings and payment flows must use the same approved backend contracts as the website.

No APK/source framework is assumed in this scaffold. Integrate the owner's existing Android source if supplied, or agree on a framework before creating a new app. Preserve existing catalogue and checkout behavior.
