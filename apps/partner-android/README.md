# Delivery Partner Android App

Reserved client application in the unified Bharat Pro Expert workspace.

Target: Android / Google Play Store.
Backend: shared Supabase project.
Authentication: Google OAuth and phone OTP (sign-up/sign-in).
Partner access must be role-restricted through Supabase RLS and trusted server-side authorization. Partner users may access only their own profile, assigned jobs, allowed job status actions and earnings data.

No APK/source framework is assumed in this scaffold. Integrate the owner's existing Android source if supplied, or agree on a framework before creating a new app.
